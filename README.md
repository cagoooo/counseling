# 輔導紀錄小幫手

把老師口語、零散的描述，整理成可以直接登錄到校務系統的正式輔導紀錄：

- **輔導內容重點**：一段話簡述發生了什麼事
- **聯繫內容**：一段話寫清楚事件經過、老師如何處理與引導、學生之後可以怎麼做

🔗 線上使用：https://cagoooo.github.io/counseling/

## 功能

| 功能 | 說明 |
|---|---|
| 姓名自動去識別化 | 送給 AI 前學生姓名換成「甲生」、同學換成「乙生、丙生…」，電話與身分證字號自動遮蔽；結果預設在本機換回真實姓名，可切換成全部用代號 |
| 輔導對象切換 | 只和學生談（不會寫出聯繫家長）／聯繫家長／學生＋家長／教師或輔導室 |
| 輔導類別、方式 | 人際、情緒、學習、常規…可複選；晤談、電話、聯絡簿、家訪… |
| 快速範例 | 同儕衝突、上課分心、作業缺交、情緒低落、危險行為、遲到常規 |
| 常見狀況標籤庫 | 8 大類 40 個國小常見狀況，點一下就加入、自動勾選類別；只點標籤不寫敘述也能產生 |
| 教師處置標籤 | 傾聽同理、約定改善目標、轉介輔導室…；勾「聯絡家長」會自動把對象改成「學生＋家長」 |
| 通報提醒 | 點選自傷、疑似霸凌、疑似受虐等標籤時，提醒依學校流程完成法定通報 |
| 一鍵改寫 | 更溫和／更客觀／更精簡／更完整，不滿意可復原 |
| 批次補登（座號制） | 點座號、勾狀況，一次最多 10 位依序產生，有進度條；只用座號不需輸入姓名 |
| 自動重試 | Google 伺服器忙碌時自動等待重試，不用重按 |
| 登錄前自動檢查 | 標出診斷或標籤化字眼、AI 可能補造的細節（如電話、家長表示）、內部用語殘留，可一鍵選取該段 |
| 追蹤輔導、學校格式、名冊、備份 | 延續前次紀錄；自訂欄位名稱與字數上限；本機班級名冊；備份成檔案與還原 |
| 公用電腦模式 | 資料只存在分頁，關閉即清除 |
| 語音輸入 | Chrome／Edge 可直接用說的 |
| 篇幅與語氣 | 精簡／標準／詳細；客觀中性／溫暖正向 |
| 兩種使用方式 | ① 填自己的 Gemini API 金鑰直接產生；② 不用金鑰，複製提示詞到 Gemini 網頁版，再把回覆貼回來自動拆段 |
| 紀錄本 | 存在自己的瀏覽器，可搜尋、載入、匯出 Excel（CSV） |
| 列印 | A4 紀錄表格式 |

## 隱私設計

- 沒有自己的伺服器，**輔導資料只存在使用者的瀏覽器**（localStorage）。
- API 金鑰只存在使用者自己的瀏覽器，並且只直接送到 Google。可選擇「不記住」，關掉分頁就會忘記。
- 免費方案的 Gemini API，輸入內容可能被 Google 用來改善服務，所以送出前一律去識別化。

## 技術

純靜態網頁（HTML + CSS + JavaScript，無打包工具），部署在 GitHub Pages。
Gemini 模型會依金鑰即時查詢可用清單（ListModels）自動挑選，模型停用時不用改程式。

- **PWA**：可「加到主畫面」，離線時也能開啟介面（AI 產生仍需網路）。
- **新版本通知**：Service Worker 偵測到新版時，畫面會跳出「重新整理載入」通知列；另有 `version.json` 輪詢當備援。網址加 `?swdemo=1` 可預覽通知列樣式。
- **社群分享卡片**：`og-image.png`（1200×630），`og:image` 網址帶版本號，避免 LINE／Facebook 卡在舊圖。

## 改版發布流程

每次修改後，**先跑自動測試、再升版、再提交**，否則可能把功能改壞，或已開著網頁的人收不到更新通知：

```powershell
npm test
powershell -ExecutionPolicy Bypass -File scripts/bump-version.ps1 -Notes "這次改了什麼"
git add -A; git commit -m "feat: ..."; git push
```

自動測試（Playwright，使用電腦上的 Microsoft Edge，不需另外下載瀏覽器）共 31 項，涵蓋去識別化與姓名顯示切換、AI 產生與改寫、逐步引導自動跳轉、給建議按鈕、登錄前自動檢查、學校格式、追蹤輔導、名冊、批次、備份還原、紀錄本篩選、公用電腦模式、錯誤處理、列印，以及手機／電腦版面（無水平捲動、頁首不重疊、最小字級）。Gemini 回應全部以模擬取代，不需要金鑰、不花額度。第一次執行前先 `npm install`。

升版腳本會同步 `version.json`、`sw.js`、`sw-register.js` 與 `index.html` 裡所有 `?v=` 版本號。

要重新產生圖示或分享圖：`npm install` 後執行 `npm run gen:images`（使用 Windows 微軟正黑體）。

本機預覽預設不啟用 Service Worker（避免快取干擾修改），網址加 `?sw=1` 才會啟用測試，`?sw=0` 關閉。
