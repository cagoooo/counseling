    ⚙️ 設定
    
        
      
    
      
    
      
    🔑 AI 金鑰
    
      
    本工具使用 Google Gemini API。金鑰只存在這台電腦的瀏覽器，並且只會直接送到 Google。
    
      
      
    還沒有金鑰？到 Google AI Studio 用學校或個人 Google 帳號免費建立。
    
      
      
      
    
      
    
        ⚠️ 免費方案的 Gemini API，輸入內容可能被 Google 用來改善服務。請維持去識別化，不要輸入身分證字號、住址、電話等個資。
      
    
      
    
        
        
      
    

      
    📝 學校紀錄格式
    
      
    依學校校務系統的欄位名稱與字數上限設定。AI 會照這個格式撰寫，超過上限時字數會標紅。改完自動儲存。
    
      
    
        
        
        
        
      
    
      

      
    🔒 公用電腦模式
    
      
    
    
      

  
  
    
    
      
    
        
    📚 紀錄本
    
        
      
    
      
    
      
    
        
        
        
      
    
      
    備份檔含紀錄與班級名冊（有學生姓名），請存在自己的電腦或學校雲端硬碟，不要傳到公開群組。
    
      
    
        
        
        
        
      
    
      
    
        
    
        
      
    
      
      
      
      
        
        
      
          
          
        
      
      
      
    
      
        

  
  
    
      
      
      
        
      👋 歡迎使用輔導紀錄小幫手
      
        
      
      
      
      三個步驟，把口語描述變成可以直接貼到校務系統的輔導紀錄。
      
      
        
        
      1. 1
        填寫輔導情境
        用口語寫發生什麼事，或直接點選「常見狀況」標籤。學生姓名只留在你的電腦，送給 AI 前會自動換成代號。
        2. 
        
      2. 2
        按「✨ AI 整理成輔導紀錄」
        幾秒鐘就產生兩段正式紀錄。不滿意可以一鍵改寫成更溫和、更客觀、更精簡或更完整。
        3. 
        
      3. 3
        檢查後複製貼上
        確認事實正確，按「複製」貼到校務系統；也可以存入紀錄本，日後查詢、列印或匯出。
        4. 
      
      

      
      🔑 第一次使用：申請免費的 Gemini 金鑰
      
      
        
        
      1. 打開 Google AI Studio 金鑰頁面，用你的 Google 帳號登入。
        2. 
        
      2. 按「建立 API 金鑰」（英文介面是 Create API key；畫面文字可能略有不同）。
        3. 
        
      3. 複製產生的金鑰（AIza 開頭的一長串英數字）。
        4. 
        
      4. 回到這裡按右上角「⚙️ 設定」，貼上金鑰後按「測試並儲存」。
        5. 
      
      
      
      沒有金鑰也能用：按「📋 不用金鑰：複製提示詞到 Gemini」，到 Gemini 網頁版貼上，再把回覆貼回來自動拆段。
      

      
      💡 小技巧
      
      
        
        
      • 批次補登：期末用座號一次寫 10 位；設定「班級名冊」後會顯示姓名，還能逐位標記已登錄。
        • 
        
      • 追蹤輔導：同一位學生再次晤談時，勾選「參考過去紀錄」，寫出前後銜接的紀錄。
        • 
        
      • 學校格式：在「⚙️ 設定」改成你們學校的欄位名稱與字數上限。
        • 
        
      • 記得備份：紀錄只存在這個瀏覽器，請定期到紀錄本「備份成檔案」。
        • 
        
      • 共用電腦：在「⚙️ 設定」開啟「公用電腦模式」，關閉分頁就自動清除。
        • 
        
      • 給建議：右下角的「給建議」按鈕會開啟阿凱老師的許願池，歡迎留下使用心得或想要的新功能。

      👥 班級名冊
